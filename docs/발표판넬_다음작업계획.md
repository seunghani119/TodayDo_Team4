검토한 원본은 2026년도 하반기 SW중심대학 오픈소스 AI·SW활용 4조 발표 판넬 양식.pptx입니다. 1장짜리 세로형으로 약 59.41 × 84.11cm이며 A1에 가깝습니다. 원본은 수정하지 않았습니다. ZIP의 슬라이드 XML과 패키지 미리보기로 확인했으며 PowerPoint 앱에서 열어 검토한 것은 아닙니다.

양식은 상단 팀명·제목·팀 정보·GitHub 주소, 제작 개요, 작품결과와 사용자 UI 예시, 기대효과 순서입니다. 이미 TodayDo의 일정·지도·예보·AI 관련 설명이 있고, 가장 큰 작품결과 영역에는 실제 화면이 아직 없습니다.

현재 기입된 이름은 대표학생 이승한, 참여학생 오동근·나성원, 지도교수 최창민입니다. 실제 제출 전에 사용자 확인이 필요합니다. 팀명·전시 제목·GitHub URL은 비어 있습니다. 이 문구는 첨부 양식의 내용이며 코드를 수정하거나 판넬을 지금 제작하라는 별도 지시로 취급하지 않았습니다.

## 권장하는 전시 메시지

**사용자가 입력한 일정과 시간별 예보를 AI가 직접 읽고 준비물과 유의점을 조언하는 일정 관리 프로그램**

제목 후보는 “TodayDo 일정과 날씨를 연결하는 AI 일정 도우미”입니다. 정식 제목과 팀명은 사용자가 정합니다.

제작 개요는 문제와 해결 흐름을 짧게 설명하고, 화면이 실제로 무엇을 하는지 결과 영역에서 보여주는 구성이 좋습니다. 고정 키워드로 활동 적합도를 점수화하는 기능이 있다고 설명하지 않습니다.

## 양식에 넣을 내용

| 영역 | 넣을 내용 |
|---|---|
| 제작 개요 | 일정의 날짜·시간·장소에 맞는 예보를 확인하고, 사용자 원문과 예보를 Claude가 함께 읽어 준비 조언을 제공한다는 목적 |

| 기대효과 | 일정 전 날씨 확인과 준비물 점검을 돕고 필요한 정보를 한 화면에서 확인할 수 있다는 기대 |
| 상단 정보 | 확정 팀명·제목, 확인된 팀원·교수 이름, 실제 공유 가능한 GitHub URL |

## 화면 수집 순서

1. 날짜·시간·장소가 명확한 시연 일정을 준비합니다. 공개해도 되는 가상 일정으로 정합니다.
2. 메인 화면에서 목록과 선택한 일정의 입력란이 함께 보이게 캡처합니다.
3. 지도에서 장소 검색 또는 클릭 후 이름·주소가 표시된 화면을 캡처합니다.
4. 예보를 받을 수 있는 일정으로 시간별 날씨와 AI 조언을 각각 확인해 캡처합니다.
5. 캡션은 해당 화면의 사용자 행동과 결과를 한 문장으로 적습니다. 코드 화면보다 기능 결과를 크게 배치합니다.

실제 예보가 없는 날짜라면 pending/partial 상태를 숨기지 않습니다. 성공한 외부 호출이 없는 상태에서 임의의 AI 답변을 실제 결과 화면처럼 만들지 않습니다. 비밀번호, API 키, 연결 문자열 등은 캡처하지 않습니다.

## 과장하지 않을 부분

- 30분 자동 갱신은 앱이 실행된 동안의 타이머이며, 앱을 꺼도 작동하는 푸시 서비스는 아닙니다.
- AI 모델은 학교 API의 Claude입니다. Claude 자체를 오픈소스 모델이라고 표기하지 않습니다.
- EF Core·Pomelo 등 실제 사용한 오픈소스 라이브러리와 공공 기상 데이터, 외부 지도·AI API를 구분합니다.
- 안전성 향상, 정확도, 시간 절약 효과는 실측하지 않았으므로 수치를 만들거나 검증된 성과처럼 단정하지 않습니다.
- 회귀 검사 통과와 실제 DB·지도·기상청·AI를 함께 사용하는 화면 시연 성공은 구분해 설명합니다.
